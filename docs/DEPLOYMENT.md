## About the domain

- The `*.vercel.app` address is the deployment domain generated by the hosting
  provider. It can be replaced or aliased with a custom domain from the
  provider's dashboard without changing the project.
- The build uses `base: './'` in `vite.config.ts`, so the same `dist/` output
  works on any domain or subpath (Vercel, GitHub Pages, Apache/XAMPP, etc.).

## Rebuilding locally

```bash
npm install
npm run build     # typecheck + production build -> dist/
```

## Offline note

All NASA data used by the game is bundled statically at build time
(`public/data/nasa/processed/`). The live site therefore needs **no NASA network
access while playing**.
